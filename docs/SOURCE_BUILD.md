# Android 最小源码构建

此 fork 补齐公开快照缺失模块的最小接口，使现有 Android 应用可以编译、启动并使用基本本地阅读流程。这不是正式发行版功能的完整恢复。

## 构建与启动

CI 基线为 Flutter 3.47.9、JDK 17、Android SDK 36；本机版本、路径和设备 ID 必须现场确认。以下启动命令不授权设备功能测试，操作边界见[共享项目规则](../.agents/PROJECT_GUIDE.md#device-testing-authorization)：

```powershell
flutter pub get
flutter analyze --no-fatal-infos
flutter build apk --debug --target-platform android-x64
flutter run -d <device-id>
```

`android-x64` 为本机模拟器构建；真实 ARM64 设备应使用 `--target-platform android-arm64`，该目标本次未验收。调试包使用独立的 `org.mewx.wenku8_flutter.source_preview` applicationId。

## 当前范围

- 主导航为“书架”“本地”和“我的”。书架展示本地可见书籍，提供纯列表、立体书架、宫格三种样式；立体模式不附带下方列表，旧混合样式偏好仍可读取。本地页保留导入、搜索、分类与批量整理，复用纯列表、立体书架和宫格三种布局；两页沿用同一布局偏好。自定义分类复用可拖动排序与左滑操作的管理界面；默认隐藏编辑和删除按钮，左滑后显示。顺序使用分类记录的可选 order 字段，旧记录保留原始顺序，重排失败不更改分类或书籍归属。立体视图的自定义分类入口也复用此管理界面。
- 手动导入支持 TXT / EPUB，仍使用系统文件选择器、原有暂存、路径校验及大小限制。
- Android 支持授权文件夹递归扫描及主共享存储扫描，发现 TXT / EPUB 后勾选导入；仍不支持其他格式转换。扫描范围、权限和限制见下方说明。
- Android 自定义语音已支持 Microsoft SSML 和 OpenAI Speech，配置、安全存储与验证边界见 [CUSTOM_SPEECH.md](CUSTOM_SPEECH.md)。局域网同步、声音增强和高级格式转换仍不可用，不伪装为已实现。
- 批量整理提供搜索与选择、分类移动、系列分卷合订及排序、移出书架与恢复、删除 App 管理副本，以及封面、旧 EPUB 排版和重复资源维护。报告图片导出仍受限；基础报告显示实际已有统计。
- 缺失曲面翻页求解器使用平面投影回退；保留现有页面快照与翻页调用接口。
- 纪念与摘录主题已使用四张四季背景，预览与 PNG 导出共用确定性回退；见 [SEASONAL_ART.md](SEASONAL_ART.md)。这不代表完整统计报告编辑 / 导出已恢复。
- SkSL 使用固定采样回退，Impeller 保留原有着色器导数路径。
- 移除缺失 DOC 转换器留下、没有源码引用且阻断 API 24 dex 构建的 POI 依赖；未提高最低 Android 版本。

已移除文库发现/排行榜、在线搜索、出版分类、账号/签到、文库云书架、评论/推荐、在线详情/目录/正文请求、站点下载、站点封面/插图传输和在线续读交接。旧正文与插图缓存只读保留，缺失内容提示导入本地文件；不会自动删除历史书籍、阅读进度、书签和备份。

本地搜索、作者与标签检索、纪念与摘录图片分享、TXT/EPUB 封面与插图仍保留。独立云盘、本地备份同步、系统/Edge TTS、字体与应用更新属于独立能力，本次未移除；因此这不是完全断网的应用。缺失模块的其他限制仍见上方列表。本次未新增依赖。

## Android 文件夹与共享存储扫描

从“本地 → 导入书籍 → 扫描本地文件夹”进入：

- **选择文件夹**：使用系统目录选择器申请持久只读授权，递归扫描该目录；不需要授予全部文件访问权限。
- **扫描共享存储**：扫描设备主共享存储。Android 11 及以上由系统“所有文件访问权限”页面授权；Android 10 及以下使用存储读取权限。此入口不覆盖可移除 SD 卡，SD 卡请通过“选择文件夹”授权。
- **格式与导入**：可选 TXT、EPUB，至少保留一种格式；先列出候选书籍，再勾选导入。沿用“关联到 App / 复制到 App”设置及现有导入校验。TXT 上限 128 MiB，EPUB 上限 512 MiB。
- **自动检查**：仅在书库前台进入或恢复时检查，沿用既有节流；不会在后台持续运行，也不会自动导入书籍。待导入数量可在扫描页查看，再手动扫描确认。
- **重复扫描**：只在导入成功后保存文件大小和修改时间；未勾选、取消、失败的文件仍可重试。已导入且元数据未变化的文件不再列出。元数据缺失时不跳过；这不是内容哈希校验，相同大小和修改时间的内容变化无法识别。
- **页面与任务**：离开扫描页不取消当前扫描，发现的候选保留在本次应用会话中，返回后继续勾选；确认导入后离开页面也会继续处理。本地书库显示扫描、准备、导入进度和结果。此行为不承诺 Android 杀进程后继续运行，也不是系统后台服务。
- **范围与保护**：跳过隐藏项；共享存储扫描另跳过整个 Android 目录及符号链接。每轮最多访问 50000 项，目录深度上限 32，遇到无权访问或上限时显示警告。扫描不会移动、修改或删除原文件。
- **断开与撤权**：断开扫描位置不删除书籍；已关联书籍需要的目录授权仍保留。系统撤销授权后显示重新授权提示，原有阅读记录不清空。

本次只实现 Android 扫描链路，不代表 iOS / HarmonyOS 的扫描能力已恢复。

## 本地整理与书籍信息

批量整理按当前书名、作者搜索，支持全选当前结果，切换搜索保留已选项。仅移出书架保留本机内容，可从整理页恢复；删除操作需确认，只处理 App 管理的内容，不改写导入来源。合订本的分卷、阅读进度和书签沿用现有映射与恢复规则。

书籍配置中的分类选择器与本地分类页面复用同一管理组件，支持新建、排序、编辑和删除；分类数据即时同步，书籍的分类归属选定后随配置保存。新建或编辑成功、取消及删除确认后均返回分类面板；各自定义分类支持独立手柄拖动、整行长按拖动排序和左滑编辑／删除，不显示长按提示；顺序持久保存并随分类备份、同步，旧分类记录保持原顺序。删除分类只将书籍归回未分类，保留原书与阅读记录。

作者、标签、系列及无标签 / 无系列属于动态筛选，不作为导入时的手动分类目标；从这些视图导入不会修改其标签或系列。扫描导入完成后释放逐本暂存副本，永久书库和外部原文件保留。

“修复与整理”可分别选择升级排版、重建封面、整理存储，逐项显示实际结果；原书和自选封面按现有维护规则保留，失败可重试。

书籍配置的“书籍信息”在作者下方提供系列名称，详情对应显示系列。系列归类与合订本是不同概念：普通书籍也可设置系列；导入前已经合并的文件可手动标记为合订本。应用内建立的虚拟合订本保留分卷关系，不通过取消标记破坏分卷与阅读记录。新增信息兼容缺少这些字段的旧记录与备份。

设置 → 使用方式可调整书架、本地、我的三个 Tab 的排列顺序，并独立选择启动后优先展示的页面。排序即时更新但不切换当前页面；旧启动页记录与页面索引保留，新增顺序设置参与备份恢复。若开启启动续读，仍按原设置恢复阅读。页头保留英文副标题，移除 02 / 03 / 04 数字前缀。宫格按实际字体测量行高，书名统一占两行，作者、系列与进度使用统一槽位；启用系列信息时，无系列作品保留空位以对齐进度条。自动与小中大封面布局共用同样的测量，避免换行和缺少系列导致基线错位。立体书架的进度条与系列信息沿用同一显示开关。

书架的随机阅读从可见本地书籍中选择，多本时避免连续选中同一本，直接沿用阅读器续读流程；空书库禁用入口。书架展示最近三本仍在本地可见书库中的阅读记录，按最近时间排序，尊重隐藏历史设置，点击继续阅读；全部历史入口沿用阅读历史页。移出书架和隐藏历史不删除原书或阅读坐标。

阅读历史的“最近阅读”使用小封面配合书名、作者、章节进度和阅读时间。封面沿用现有加载与缺图回退，整行继续阅读和历史操作菜单沿用原有行为。

# 项目图标与动效设计

遵守[共享项目约束](../../PROJECT_GUIDE.md)。以当前代码和[图标系统规范](../../../docs/ICON_SYSTEM.md)为准，视觉语汇参考[设计规范](../../../docs/DESIGN.md)。图标试验场为忽略的本地文件 `.local-notes/design/library-lab/icon-playground.html`，由原始 `.local-notes/design/library-lab/icons.html` 逐字节复制；不要覆盖原始页。

## 先读现状

- 先在原始图标页和试验场检查已有图标、分组、明暗主题、选中状态及动作帧。沿用现有语义时优先复用，不要为了展示重复造图。
- 图标事实以 `lib/archive_icons.dart`、`lib/archive_icon_art.dart`、`lib/archive_icon_fold_art.dart` 和 `lib/archive_icon_motion.dart` 为准；输出与 Flutter 几何、当前图标系统或文档不一致时，先查明差异，不从旧截图臆测。
- 把需求拆成语义、默认姿态、状态姿态和触发动作。区分持续状态（例如选中 / 未选中、播放 / 暂停）与一次性反馈（点击、入场）；静态信息图标保持安静。

## 造型与 SVG

- 默认采用 `viewBox="0 0 24 24"`、`currentColor`、1.72 单位笔画、圆角端点与连接。小尺寸或高对比度等例外，沿用 `docs/ICON_SYSTEM.md` 的实际规则并标注原因。
- 延续“折页墨线、纸页与档案”的原创语言：用书脊、纸张、切角、折页、墨块和克制留白表达含义；线与局部填色从同一前景色继承。避免彩色底片、无语义装饰、细碎小细节及与现有图标不一致的拟物或通用图库拼接。
- 各姿态保持同一画布、视觉重心、轮廓识别度和可插值的结构。若状态间需要形变，保持对应路径点或拆分一致的部件；不要依赖交换整个 SVG 造成的跳变来伪装平滑变形。
- 使用内联、可离线显示的 SVG；保留 `aria-hidden="true"` 等装饰性图标语义。不要用脚本、外部图片、字体图标或外部网络资源构造图形。
- 每个候选至少给出正常态及需求涉及的状态姿态；动作另提供从起势、主动作、回弹到落定的可检查帧。为图标提供稳定 `id`、简短中文标签和正确分组。

## 加入本地试验场

- 把候选添加到 `.local-notes/design/library-lab/icon-playground.html` 的 `assetData` 图标集合中，补齐 `id`、`label`、`group`、默认 `svg`、状态 `activeSvg`（若存在）以及顺序一致的 `frames`。在 `manifestData` 的图标表同步登记 ID、路径 / 来源说明和相关元数据；不要替换或删改已有图标数据。
- 让候选使用页面已有的尺寸选择、姿态 / 配对选择、播放与逐帧滑杆、深色和减少动态效果选项。动作帧必须能停在中间检查；单纯展示 CSS 自动循环不足以供评审。
- 保持页面现有暖纸色、墨色、细线与版面层级。只改候选所需的数据或最小页面逻辑，不重排整页或更改原始 `icons.html`。
- 更新后检查 JSON 可解析、每个姿态的 SVG 可独立解析，记录候选 ID 和本次新增状态 / 帧。直接用浏览器打开 `.local-notes/design/library-lab/icon-playground.html`，确认网格、放大舞台、明暗主题、姿态切换与逐帧预览可用；评审目标是视觉一致性，静态检查不能代替页面观感。
- 用户根据试验场反馈后，直接调整候选并保留唯一当前版本；不要把未接受的图标接入 Flutter 生产组件。

## 动效约束

- 动作表达图标含义，保持轻、短、可逆的视觉反馈；不移动布局、不改变命中区域、不借助闪烁或大幅缩放吸引注意。
- 当前系统的参考时间为：入场 520 ms，点击完整动作 640 ms，状态形变 380 ms；多部件依序错峰与回弹参考 `ArchiveIconMotion`。这些是当前系统参数，候选需要变化时说明理由，不照搬到不适用的图标。
- 状态转换要能从当前姿态连续接续；取消手势不得触发完整成功动作。装饰性闲置图标不持续循环，除非明确属于 ambient 展示且满足现有生命周期约束。
- 试验场应保留减少动态效果下的静止姿态。接入应用时还需服从 `MediaQuery.disableAnimations`、用户性能偏好、页面可见性和 `TickerMode`；skill 不替代运行时生命周期实现。

## 从候选接入应用

- 本 skill 默认只产出试验场候选与 SVG，不修改 Dart 图标清单或运行时行为。只有用户明确要求接入时，才将已确认候选落到现有绘制器 / 动效架构，并检查语义、无障碍标签、主题继承、减少动态效果、低性能模式、页面隐藏行为和已有兼容映射。
- 接入时复用 `ArchiveSymbol`、`ArchiveIcon` 和 `ArchiveIconMotion`。不要引入第二套图标依赖、全局图标框架或独立颜色系统；如果 SVG 动态效果无法由现有 Flutter 绘制器承载，先评估最小实现并说明差异。
- Flutter 代码或视觉行为发生变化后，按 `flutter-ui-regression` 执行匹配的静态 / 定向验证；试验场纯 HTML / SVG 变更做浏览器实际检查。不得把静态 SVG 检查描述为 Flutter 设备端验收。

交付时列出候选 ID、姿态与动作帧、试验场路径、实际检查方式及未检查项。候选通过视觉评审只代表试验场确认，不代表已接入或完成设备验收。
